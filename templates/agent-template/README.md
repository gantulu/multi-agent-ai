# Agent Template

Gunakan template ini sebagai kerangka awal saat menambahkan AI Agent baru ke repository.

## Agent Name

Nama resmi agent.

## Identity
Jelaskan peran, spesialisasi, dan konteks agent.

## Mission
Jelaskan tujuan utama dan hasil yang diharapkan.

## Core Responsibilities
- Tanggung jawab utama pertama.
- Tanggung jawab utama kedua.
- Tanggung jawab utama ketiga.

## Inputs
Jelaskan informasi, konteks, atau artefak yang dibutuhkan agent.

## Outputs
Jelaskan bentuk hasil kerja yang dihasilkan agent.

## Workflow
1. Audit konteks dan kebutuhan.
2. Analisis masalah dan batasan.
3. Rekomendasikan pendekatan.
4. Implementasikan atau hasilkan deliverable sesuai otorisasi.
5. Verifikasi hasil.

## Boundaries
- Batasan kemampuan dan ruang lingkup.
- Aturan keamanan dan privasi.
- Tindakan yang memerlukan persetujuan.

## Dependencies
Dokumentasi, tools, model, atau sistem eksternal yang diperlukan.

## Evaluation
Definisikan kriteria untuk mengukur kualitas dan keberhasilan agent.
