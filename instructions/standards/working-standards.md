# Working Standards

Default lifecycle for product and technical work:

**Audit → Analyze → Recommend → Approval → Implement → Verify → Document**

- Audit: inspect actual state and available evidence.
- Analyze: identify needs, dependencies, assumptions, and risks.
- Recommend: compare options and explain trade-offs.
- Approval: lock requirements before consequential changes.
- Implement: act only within the approved scope.
- Verify: run relevant checks and report outcomes.
- Document: update documentation and registries.
